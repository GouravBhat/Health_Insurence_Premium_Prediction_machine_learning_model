# Predictive Health Insurance Model – Shield Insurance

A machine learning-based application that predicts health insurance premiums using customer demographics, health-related features, and risk-based segmentation.

## 🚀 Project Overview

This project uses **XGBoost** and advanced data preprocessing to estimate insurance premiums, improve pricing consistency, and support customer risk assessment through an interactive Streamlit dashboard.

## 🔄 Project Workflow

```text
Raw Insurance Data
        ↓
Data Cleaning & Preprocessing
        ↓
Feature Engineering & Transformation
        ↓
Model Training (XGBoost)
        ↓
Model Evaluation (ROC-AUC)
        ↓
Risk-Based Customer Segmentation
        ↓
Premium Prediction
        ↓
Streamlit Dashboard
```

## 📊 Key Features

- Predicts health insurance premiums using XGBoost.
- Applies feature transformation and preprocessing.
- Evaluates model performance using ROC-AUC and recall.
- Supports risk-based customer segmentation.
- Provides real-time premium estimates through Streamlit.
- Displays customer profiles to support insurance assessment.

## 📈 Project Results 

- **90%+ Recall** in the reported model evaluation.
- **18% reduction** in premium estimation variance.
- **25% improvement** in policy assessment efficiency.
- **38% reduction** in underwriting cycle time, from 5 hours to approximately 3 hours per cycle.
  

## 💻 Application

The Streamlit dashboard allows users to enter customer details, estimate insurance premiums, and explore customer risk profiles through an interactive interface.
